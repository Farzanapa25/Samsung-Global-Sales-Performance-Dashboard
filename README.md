# 📊 Samsung Global Sales Performance Dashboard

## 📘 Introduction
The global electronics market is highly competitive, where companies focus on innovation, pricing, and customer satisfaction.  
This project analyzes Samsung global sales data to understand performance across regions, products, and customer segments using an interactive Excel dashboard.

## 🔹 Project Overview
This project focuses on analyzing Samsung global sales data using Excel.  
The dashboard provides clear insights into sales trends, product performance, and customer behavior.

## 🎯 Objectives
- Analyze overall sales performance  
- Identify top-performing products  
- Evaluate revenue and profit  
- Understand customer segments and sales channels  
- Support business decision-making
- 
## 📁 Dataset Information
The dataset contains detailed sales information of Samsung products across multiple countries.

### Key Columns:
- Date, Year, Month  
- Country, Region  
- Product, Category  
- Unit Price, Units Sold  
- Revenue, Profit  
- Sales Channel  
- Customer Segment  
- Customer Rating  
- Return Status  

## 🛠 Tools Used
- Microsoft Excel  
- Pivot Tables  
- Charts & Graphs  
- Slicers (Filters)  

## 📊 Dashboard Features
- KPI Metrics (Revenue, Profit, Units Sold, Rating)  
- Monthly Revenue Trend  
- Revenue vs Profit Analysis  
- Top 10 Products  
- Sales Channel Distribution  
- Customer Segment Analysis  
- Category-wise Revenue  
- Country-wise Sales  

## 🔄 Data Preprocessing
- Removed missing and duplicate values  
- Handled null values  
- Standardized text values  
- Converted date into Year and Month  
- Created calculated fields  

## 📈 Key Insights
- A few products contribute major revenue  
- Some regions perform better than others  
- Online sales channel has strong contribution  
- Customer segments show different buying patterns  

## 💡 Suggestions
- Focus on high-profit products  
- Improve low-performing regions  
- Optimize pricing strategies  
- Strengthen online sales channels  
- Improve customer satisfaction
